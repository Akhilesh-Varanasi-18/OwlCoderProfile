Complexity Analysis · Module 1Article Time & Space Complexity

Every algorithm spends two things: time and memory. Complexity analysis measures both without running the code — by asking how the work grows as the input grows.

We write that growth in Big-O. Constants and smaller terms are dropped, because at scale only the fastest-growing term matters.

The six classes below are the ones you will meet most. A nested loop over n items is O(n²); a binary search is O(log n); a hash lookup is O(1).

Complexity Analysis · Module 1Notes My notes
  • Big-O describes growth, not seconds.
  • Drop constants and lower-order terms.
  • Nested loops over n → O(n²).
  • Space counts extra memory, not the input.
  • Trade-off: hash map = O(1) time, O(n) space.
