Vectors in C++

DSA · Module 02 · Article 1 of 3

Marked as read
What is a Vector?

A vector is a dynamic array from the C++ Standard Template Library. It stores elements in contiguous memory like a normal array, but it can grow and shrink automatically at runtime. You never declare its size up front.

#include <vector>
using namespace std;

vector<int> v;              // empty
vector<int> a = {1, 2, 3};   // initialised
vector<int> b(5, 0);       // five zeros

Real life: a wedding guest list where you don't know the final headcount. You keep adding chairs as more people confirm, instead of booking a hall for an exact fixed number.

01 — Learn

        
Learn the concept.
Practice the problem.
Master the skill.

        

          
Pick a course

            
DSA, Advanced Data Structures, Python, Java and SQL. Each track shows articles, videos, trainer
              problems, trainee problems, labs and notes at a glance.

          
Follow the learning path

            
Modules run in sequence with a live completion percentage, and the platform always marks the one
              module you should continue from.

          
Read it, then watch it

            
Every module carries written articles with a contents rail, worked code samples and real-world
              analogies, alongside recorded video on the same topic.

          
Code it in the browser

            
Trainer-curated problems sit inside the module. Write, run and submit without ever leaving the
              lesson you are in.

03 — Compete

        
Compete. Climb.
Conquer.

        

          
Register, then wait for the gun

            
Scheduled contests with a live countdown, a registered-student count and a fixed duration. Everyone
              starts on the same second.

          
Four questions. One sitting.

            
Switch between questions freely, submit each one as its test cases pass, then make a final
              submission. The timer never stops.

          
The board decides

            
Ranked by problems solved, then points, then penalty time. Easy carries twenty points, medium forty
              and hard sixty.

        

        

      

      

    

  







  

    

      

        
04 — Track

        
One click.
Complete visibility.

        

          
A year of work, in one grid

            
The progress heatmap shows every solved day across the last year, alongside totals by difficulty and
              your linked LeetCode, CodeChef, HackerRank and GitHub profiles.

          
Reports down to the module

            
Course overview, module view and per-module performance with solve counts, attempts, average time
              and a rating against the threshold for each difficulty.

          
Journey to interview readiness

            
Average solve time week on week against a target. Ten minutes for easy, twenty-five for medium,
              thirty-five for hard. Speed is what interviews actually test.

        

        

      

      

    

  







  

    

      

        
05 — Improve

        
An AI tutor that knows
where you are
in the problem.

        

          
Before you start

            
Understand the problem first. Ask for an approach, a hint to begin, a plain-language explanation, or
              a walk through the sample input and output.

          
After you start

            
Stuck is a state the tutor recognises. Hidden cases failing, a time limit exceeded, wrong output, or
              simply no idea what comes next.

          
Once you have submitted

            
Accepted is not the end. Review code quality, get the time and space complexity, and rehearse how you
              would explain the solution in an interview.
